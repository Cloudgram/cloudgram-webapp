# 📱 Cloudgram Web

Веб-приложение для облачного хранения файлов с интеграцией через Telegram бота.

## 📝 Описание проекта

Cloudgram - это веб-приложение для управления файлами в облачном хранилище, использующее Telegram как основную платформу для хранения файлов. Пользователи могут загружать и управлять своими файлами через удобный веб-интерфейс, в то время как все данные безопасно хранятся в Telegram. Проект построен с использованием React.

### ✨ Основные возможности

-   🔐 Авторизация через Telegram
-   📂 Управление файлами и папками
-   📤 Загрузка и скачивание файлов
-   📊 Просмотр информации о хранилище
-   ⭐ Система подписок (Premium)
-   🎯 Удобный пользовательский интерфейс

## 🛠️ Технологии

-   **Frontend Framework:** ⚛️ React + TypeScript
-   **Стилизация:** 🎨 SCSS Modules
-   **Управление состоянием:** 🔄 TanStack Query (React Query)
-   **Роутинг:** 🔀 React Router
-   **Анимации:** 💫 GSAP
-   **Валидация данных:** ✅ Zod
-   **Сборка:** ⚡ Vite

## 🏗️ Основные компоненты

### 📄 Страницы (pages/)

-   **AuthPage** - 🔑 Страница авторизации
-   **MainPage** - 🏠 Главная страница с файлами и папками
-   **AuthGuard** - 🛡️ Компонент защиты роутов

### 🧩 Компоненты (components/)

-   **Header** - 📱 Шапка с навигацией и информацией пользователя
-   **Footer** - 🔽 Нижняя панель навигации
-   **FoldersList** - 📂 Список файлов и папок
-   **UserPanel** - 👤 Панель информации о пользователе
-   **Filters** - 🔍 Фильтры и создание файлов/папок
-   **Breadcrumbs** - 🗺️ Навигационная цепочка
-   **SearchInput** - 🔎 Поиск файлов
-   **FileActionMenu** - 📄 Меню действий с файлами
-   **FolderActionMenu** - 📁 Меню действий с папками

### 🔌 API (api/)

-   **Auth.ts** - 🔐 Авторизация
-   **Files.ts** - 📄 Управление файлами
-   **Folders.ts** - 📁 Управление папками
-   **User.ts** - 👤 Информация о пользователе

### 🎣 Хуки (hooks/)

-   **useUserQuery** - 👤 Получение данных пользователя
-   **useFolderQuery** - 📂 Получение содержимого папки
-   **useFolderHistory** - 📜 История навигации по папкам
-   **useClickOutside** - 🖱️ Определение клика вне элемента

## 🚀 Установка и запуск

1. Клонировать репозиторий:

```bash
git clone [repository-url]
```

2. Установить зависимости:

```bash
npm install
```

3. Запустить в режиме разработки:

```bash
npm run dev
```

4. Сборка для продакшена:

```bash
npm run build
```

## 🔌 API Endpoints

Базовый URL: `https://api.cloudgram.online`

-   `/user` - 👤 Информация о пользователе
-   `/folder/{id}` - 📂 Получение содержимого папки
-   `/file` - 📤 Загрузка файла
-   `/file/{id}` - 📥 Скачивание/удаление файла

Документация по API: `https://api.cloudgram.online/docs#/`
